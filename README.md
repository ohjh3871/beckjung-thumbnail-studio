# 백정닷컴 썸네일 스튜디오 v0.1

GitHub Pages에서 서버 없이 작동하는 무료 이미지 합성 MVP입니다.

## 배포
1. GitHub에 `beckjung-thumbnail-studio` 공개 또는 비공개 저장소를 만듭니다. (GitHub Pages 사용 가능 여부는 계정/저장소 설정에 따라 달라질 수 있습니다.)
2. 이 폴더의 `index.html`을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. `https://ohjh3871.github.io/beckjung-thumbnail-studio/` 에서 확인합니다. 반영까지 시간이 걸릴 수 있습니다.

## 사용법
사진 업로드 → 스타일 선택 → 원본 화면에서 상품 외곽을 여러 점으로 지정 → 영역 완성 → 결과 화면에서 드래그로 위치 조절 → 600×600 JPG 다운로드.

## 제한 사항
- 현재 **자동 AI 분류/자동 배경 제거 없음**. 상품 영역은 수동으로 지정해야 합니다.
- 배경은 참고 스타일의 간단한 절차적 그래픽이며, 제공된 예시 사진을 그대로 재현하지 않습니다.
- 상품 픽셀은 원본에서 잘라 합성하지만, 다각형 외곽선이 부정확하면 상품이 잘릴 수 있습니다.
- 직원 로그인, 작업 공유, 카페24 API 연동은 아직 없습니다.
- 웹사이트에 접근할 수 있는 누구나 도구를 사용할 수 있습니다. 고객 데이터/비밀정보를 업로드하지 마세요.
- 외부 이미지 전송 없음. 모든 처리는 사용자 브라우저에서 수행됩니다.
